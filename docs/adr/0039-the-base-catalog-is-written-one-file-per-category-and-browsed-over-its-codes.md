# The base catalog is written one file per category and browsed over its codes

ADR 0012 made the base catalog code: one file of 86 Norme de bază. Its second edition, "octombrie 2026 (a 2-a)", brings it to 599 norms in 23 categories, from Demolări to Organizare de șantier, with the instalații (sanitare, termice, gaze, ventilație, electrice, curenți slabi), reparații și consolidări and confecții metalice that firms asked for first. One file would be some thirteen thousand lines that no review can read, so the catalog is now written one file per category under `packages/backend/convex/catalog/base/`, the Resurse that more than one category consumes live in `base/resources.ts`, and `catalog/baseNorms.ts` puts the categories together in the order works follow on a site. The categories themselves, each with a key, a code prefix and a name, are the small module `catalog/baseCategories.ts`, which the interface imports for its category chips while the norms stay on the server.

## Consequences

- A category's file is named in camelCase (`curentiSlabi.ts`, `gipscarton.ts`): Convex deploys every file under `convex/`, and a module path may hold only letters, digits, underscores and periods. A test checks the names. Instalații sanitare, the largest, is written in two files, `sanitareConducte.ts` (DV-SAN-01 to 40) and `sanitareObiecte.ts` (DV-SAN-41 on); its new norms go at the end of `sanitareObiecte.ts`.
- A category owns a series of codes: `DV-`, its prefix and two digits (DV-ZID-03), numbered in rising order in its file and at most 99 per category. A new norm goes at the end of its category's file with the next number; a withdrawn norm leaves its number empty (ADR 0012). Tests check that every category's series rises without repeats, that the set of categories in the norms is the set in `baseCategories`, and everything ADR 0012 already checked.
- The catalog is browsed by category without a field for it: the index on codes lists the published public norms from `DV-ZID-` up to, not including, `DV-ZID.`, and `catalog.norms.listBaseCategory` returns them in the order of their codes, at most 100, which a category never reaches. Words typed are narrowed to a category with the search's existing `category` filter. The schema is unchanged: a norm's `category` stays the name it shows.
- /catalog shows the categories as chips above the list, with "Toate" first, in rows from tablet width up and in one row that scrolls sideways on a phone. The category is in the address, `/catalog?category=zid`, so Back from a norm's page and links to a category open it even on a page kept from an earlier visit (ADR 0029). A norm's page links its category to the catalog browsed by it. The add-norm sheet of a Deviz shows the same chips under its search, in one row with a thin scrollbar: a category alone lists its norms, and words typed search within it, so a firm finds "the plumbing norms" without knowing a word of their titles. When words find nothing in the category, both offer the search over all categories, and the sheet offers a norm from Devize AI only after that search, so the AI doesn't write a norm the catalog has in another category.
- The 86 norms of the first edition are unchanged, codes, texts and resources included, so publishing the second edition adds 513 norms and makes no new versions, and the systems and rules that cite codes (ADR 0028) still hold.
- Reference prices stay indicative Romanian prices at the edition's date, rounded, in lei without VAT, with the trades the new categories need (Lăcătuș confecții metalice, Sudor, Tehnician de climatizare, Tehnician de curenți slabi, Topometrist and others) at hourly rates without CAM. A resource that more than one category consumes is defined once in `base/resources.ts`; a material only one category uses sits at the top of that category's file. Tests check that one name means one unit and one price across all files and that no name is defined in two files, so a material a second category starts to use moves to `base/resources.ts`.
- Instalații de gaze and instalații electrice norms price the work of a firm that holds the authorisation the law requires (ANRE); the norm does not stand in for the authorisation, the project or the acceptance by the distributor, which the norms' texts leave out. Works common on Romanian sites in 2026 are in: pompe de căldură, fotovoltaice cu invertor și baterie, stații de încărcare, ventilație cu recuperare, detecție de incendiu, consolidări cu fibre de carbon. Drumuri și poduri, rețele edilitare mari, structuri metalice industriale and piscine are not, and come in a later edition when firms ask for them.
- Admin → Catalog de bază reads every norm of the edition with a few queries each, about two thousand queries and six thousand documents for 599 norms, within Convex's limits for one query. Publishing stays in batches of twenty norms: thirty batches each time, the first in the publish mutation and the other twenty-nine in the background. The tests drain those batches by watching the scheduled functions, since convex-test can come back between two of them.
