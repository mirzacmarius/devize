# The base catalog ships with the code

ADR 0002 decided that Devize writes its own catalog of Norme de bază. That catalog is code: `packages/backend/convex/catalog/baseNorms.ts` holds each norm's code, title and unit, what it includes and leaves out, how it is measured, and the Resurse one unit consumes, with reference prices. A change to it is a pull request like any other, reviewed and tested before anyone prices with it. A super admin then publishes it from Admin → Catalog de bază, which shows each norm of the edition as new, changed or published, and publishes the new and changed ones as verified Norme de bază.

## Consequences

- Publishing compares each norm in the code with its published version, field by field and resource by resource. A new norm becomes version 1. A changed one becomes a new version in the same lineage that supersedes the published one, so devize priced with the old version keep their copy (ADR 0005). An unchanged one is left alone, so publishing again changes nothing. Twenty norms are published per transaction and the rest follow in the background.
- Codes are `DV-`, the category's prefix and a number, such as DV-ZID-03. A norm keeps its code for good: a change is a new version under the same code, and a withdrawn norm's code is not given to other work, since publishing would add that work to the old norm's lineage.
- Base norms are edited in the code, not in the app. If a super admin changes one in the app, the catalog page shows it as changed and the next publish replaces it with the code's version; archiving one that is still in the code brings it back at the next publish. To withdraw a norm, remove it from the code and archive it from its page: a norm that is no longer in the code stays published until it is archived.
- Reference prices are indicative Romanian prices at the edition's date, in lei without VAT like every price in a Deviz. Labour is an hourly rate without CAM, which the Recapitulație adds. They come last in the price order of ADR 0005, after the firm's own rates and prices, its Produse alese and store listings, so a Deviz built from base norms has a price on every line from the start, and each firm replaces them with its own.
- The catalog shares each Resursă among the norms that consume it: "Zidar" is one resource for every norm that needs a mason, so one Tarif prices them all. Publishing gives a shared Resursă the catalog's reference price only when it has none, and never overwrites a price it already has.
- `BASE_EDITION` names the edition, now "octombrie 2026", and each norm records the edition it was published in. A new edition is a change to the code: the norms that changed get new versions in it, and the others keep theirs.
- Tests check the whole catalog: unique codes in their category's series, canonical units, positive quantities, a reference price for every resource except a percentage, the same unit and price for a resource in every norm, and Romanian with comma-below diacritics.
- Only Devize's own norms live in this public repository. Producers' norms still reach the catalog only through the super-admin import (ADR 0006).
